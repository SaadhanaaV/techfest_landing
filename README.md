# Techfest, IIT Bombay — Official Landing Page Redesign

A futuristic, high-energy landing page concept designed and built for the **Web & Tech Team screening task** of **Techfest, IIT Bombay** (Asia's Largest Science and Technology Festival).

> **Important:** Strictly built using **zero 3D libraries/assets** (no Three.js, Spline, or GLTF models), relying entirely on 2D HTML5 canvas dynamics, custom CSS animations, modern typography, and glassmorphism styling.

## ⚡ Key Highlights & Architecture

- **Canvas Cyber-Mesh Background:** Interactive 2D HTML5 Canvas particle/constellation field reacting to mouse coordinates without external 3D engine overhead.
- **Bento Grid Architecture:** Clean, responsive flagship showcase with dynamic mouse-following border highlights and gradient card overlays.
- **Social Proof Counter Strip:** High-contrast statistical banner highlighting festival legacy (1,75,000+ footfall, ₹50L+ prize pool).
- **Infinite Marquee Ticker:** Seamless CSS ticker showcasing past keynote guests and Nobel Laureates who have visited the Techfest stage.
- **Glassmorphism & HUD Elements:** Futuristic ambient glows, corner brackets, and terminal-inspired UI accents representing robotics and deep-tech.
- **Fully Responsive:** Tested across mobile, tablet, and ultra-wide displays.

---

## 🧭 Page Structure

1. **Sticky Cyber-Navbar:** Quick anchors (Events, Competitions, Workshops, Exhibitions, Technoholix), CA portal link, and glowing registration CTA.
2. **Hero Section:** Fest edition, bold headline typography, event metadata (Dates, IIT Bombay venue), and dual action CTAs.
3. **Metrics Bar:** Key fest numbers with high-contrast glowing accents.
4. **Flagship Pillars (Bento Grid):**
   - *Competitions:* Robowars, Meshmerize, Aero-modelling, Coding.
   - *Workshops:* AI/ML, IoT, Ethical Hacking, Robotics.
   - *Exhibitions:* Global research showcases and military tech.
   - *Technoholix & Ozone:* Pronites, laser shows, and EDM night carnivals.
   - *Lectures:* Keynotes by Nobel Laureates and industry leaders.
5. **About / Festival Overview:** Legacy statement and preview container for the annual aftermovie.
6. **Campus Ambassador (CA) Program:** Dedicated engagement banner highlighting rewards, certification, and registration access.
7. **Past Luminaries (Infinite Ticker):** Dr. A.P.J. Abdul Kalam, Sophia the Robot, Steve Wozniak, Rakesh Sharma, Kip Thorne, etc.
8. **Footer:** Contact details for festival convenors, IIT Bombay address mark, and official social handles.
